# Audio credits

Every sound in the game is synthesized live in the browser with the Web Audio API (`src/audio.ts`).
There are no audio files, so there are no third party licenses to track.

| Sound | Source |
|---|---|
| Interface clicks, panel open and close, found chime, door, wake up | Self made (oscillators) |
| Footsteps (carpet in the dorm, wood at home) | Self made (filtered noise) |
| Cat meow and purr | Self made (oscillators) |
| Speaker loop (EDM, 140 BPM, half time) | Original, written in code for this site |
| Piano notes | Self made (additive synthesis) |
| Ambience: dorm hum and distant campus blips, rain at home | Self made (filtered noise and oscillators) |

If recorded sounds are added later, list each file here with its source URL and license.
